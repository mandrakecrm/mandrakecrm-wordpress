# Security policy

## Supported versions

The latest release is supported. Security fixes are released as a new version on WordPress.org and as a GitHub Release here.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Write to **hello@mandrakecrm.com** with "Security" in the subject, or use [GitHub's private vulnerability reporting](https://github.com/mandrakecrm/mandrakecrm-wordpress/security/advisories/new) on this repository. Include the plugin version, the steps to reproduce, and the impact you believe it has.

You will get an acknowledgement within 3 business days, and a fix or a clear status within 14 days for confirmed issues. We will credit you in the changelog unless you prefer otherwise.

## Scope

- This plugin (everything in this repository).
- The MandrakeCRM service it talks to. Reports about the service are welcome at the same address.
